# Git Practice

## Descripción del proyecto

Este proyecto recoge mi primera práctica con **Git** y sirve para aprender a crear un repositorio, organizar archivos y registrar su evolución mediante commits.

Durante la práctica he creado:

- Una estructura formada por cuatro carpetas con sus respectivos archivos de texto.
- Una página HTML básica de contacto.
- Una imagen como recurso adicional del proyecto.
- Este README para documentar el trabajo realizado.

## Problemas y dudas

Por el momento no tengo dudas pendientes. La práctica me ha permitido familiarizarme con el flujo básico de Git y comprender cómo cada commit representa un cambio concreto dentro del proyecto.
